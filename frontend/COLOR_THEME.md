# Color Theme Guide

## New Theme: White, Orange, Red

### Primary Colors:
- **Primary/Accent**: Orange (#ea580c - orange-600, #f97316 - orange-500)
- **Secondary**: Red (#dc2626 - red-600, #ef4444 - red-500)
- **Background**: White (#ffffff), Light Orange (#ffedd5 - orange-50), Light Red (#fee2e2 - red-50)
- **Text**: Dark Gray (#1f2937 - gray-900), Medium Gray (#6b7280 - gray-600)

### Replacements:
- `from-blue-50 via-white to-purple-50` → `from-white via-orange-50 to-red-50`
- `bg-blue-600` → `bg-orange-600`
- `bg-purple-600` → `bg-red-600`
- `text-blue-600` → `text-orange-600`
- `text-purple-600` → `text-red-600`
- `border-blue-200` → `border-orange-200`
- `border-purple-200` → `border-red-200`
- `from-blue-600 to-purple-600` → `from-orange-600 to-red-600`
- `hover:from-blue-700 hover:to-purple-700` → `hover:from-orange-700 hover:to-red-700`

### Gradients:
- Progress bars: `from-orange-500 to-red-500`
- Buttons: `from-orange-600 to-red-600`
- Backgrounds: `from-white via-orange-50 to-red-50`
